## Настройка каналов

Укажите ID канала по умолчанию в `LOG_CHANNEL_DEFAULT`. Для отдельного маршрута добавьте ключ действия и ID канала в `LOG_CHANNEL_OVERRIDES`:

```dotenv
LOG_CHANNEL_OVERRIDES='{"voice_join":123456789012345678,"role_added":234567890123456789}'
```

Неизвестные ключи и неположительные или нечисловые ID приводят к ошибке при запуске.
